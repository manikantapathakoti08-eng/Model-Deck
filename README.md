**Local AI Integration (Ollama):**
Please note that Ollama runs locally on your machine. Because of this, it will not function out-of-the-box on the live website unless your local computer is running and powered on 24/7. To host Ollama natively in a production environment, you will need to deploy it on a cloud server equipped with more than 8 GB of RAM to handle model inference reliably.
